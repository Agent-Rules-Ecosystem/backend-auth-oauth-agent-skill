# ⚡ Comandos de Auth / OAuth2 Agent Skill (`backend-auth-oauth-agent-skill`)

| Comando | Acción | Descripción |
|---|---|---|
| `$auth` | Bootstrap | Inicializa la skill y carga contexto del dominio. |
| `$auth:audit` | Auditoría | Auditar flujos OAuth2, JWT, tokens y seguridad de endpoints. |
| `$auth:jwt` | Generación | Configuración de firmadores y verificadores JWT. |
| `$learnskill backend-auth-oauth-agent-skill [propuesta]` | Aprendizaje | Registrar propuesta de mejora específica para `backend-auth-oauth-agent-skill` en `overview/learning.md` |
| `$revlearnskill` | Revisión | Clasificar e inspeccionar propuestas de aprendizaje acumuladas en `overview/learning.md` |
